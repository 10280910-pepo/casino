JSON

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para almacenar y transmitir información de manera organizada.

¿Por qué es importante?

JSON es muy utilizado para intercambiar información entre aplicaciones, servidores y APIs porque tiene una estructura sencilla y fácil de leer.

Pares clave-valor

Los datos en JSON se organizan mediante pares formados por una clave y un valor. 

{
    "nombre": "Royal Club",
    "categoria": "Web",
    "activo": true
}

Objetos

Un objeto JSON se encuentra entre llaves y puede contener diferentes propiedades. 

{
    "producto": "Royal Club",
    "precio": 0,
    "disponible": true
}

Arreglos

Los arreglos permiten guardar varios valores dentro de una lista. 

{
    "tecnologias": [
        "HTML",
        "CSS",
        "JavaScript"
    ]
}

Objeto JavaScript y cadena JSON

Objeto JavaScript JSON
{ nombre: "Royal Club" } { "nombre": "Royal Club" }
Es utilizado directamente dentro del programa. Es una cadena de texto con un formato estándar.

JSON y las APIs

Las aplicaciones web pueden comunicarse con servidores mediante APIs. El servidor puede enviar información en formato JSON y JavaScript puede recibir esos datos para mostrarlos en la página. 

fetch("https://ejemplo.com/api/datos")
    .then(respuesta => respuesta.json())
    .then(datos => console.log(datos));
