JavaScript Vanilla

JavaScript es un lenguaje de programación utilizado principalmente para agregar interactividad y comportamiento a las páginas web. Permite crear páginas dinámicas que pueden responder a las acciones realizadas por los usuarios.

¿Para qué se utiliza?

JavaScript permite crear botones interactivos, formularios, animaciones, menús, validaciones, calculadoras, videojuegos, aplicaciones web y muchas otras funciones.

HTML, CSS y JavaScript
