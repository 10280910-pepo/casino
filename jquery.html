jQuery

jQuery es una biblioteca de JavaScript creada para facilitar el desarrollo de páginas web. Permite realizar tareas como seleccionar elementos, modificar contenido, manejar eventos y crear animaciones con una sintaxis sencilla.

¿Por qué nació jQuery?

jQuery nació para simplificar el trabajo de los desarrolladores y facilitar la compatibilidad entre diferentes navegadores. En sus primeros años permitió realizar muchas tareas de JavaScript utilizando menos código.

Sintaxis básica

Una de las características más conocidas de jQuery es el símbolo $, utilizado para seleccionar elementos. 

$("#mensaje").hide();

$(".boton").click(function() {
    $("#mensaje").show();
});

Ventajas

  • Sintaxis sencilla.
  • Facilita la manipulación del HTML.
  • Permite crear animaciones fácilmente.
  • Facilita el manejo de eventos.

Desventajas

  • Agrega una dependencia externa.
  • JavaScript moderno puede realizar muchas de sus funciones.
  • No siempre es necesario para proyectos pequeños.

jQuery frente a JavaScript moderno

jQuery JavaScript moderno
Utiliza $ para seleccionar elementos. Utiliza métodos como querySelector.
Facilita algunas animaciones. Puede utilizar CSS y JavaScript.
Necesita cargar la biblioteca. No necesita una biblioteca externa.
