Web Hosting y Dominios

¿Cómo se pone una página web en Internet?

Para publicar una página web en Internet necesitamos almacenar sus archivos en un servidor conectado a Internet. Este servicio se conoce como Web Hosting.

Web Hosting

El Web Hosting es un servicio que proporciona espacio y recursos para almacenar los archivos de un sitio web y permitir que otras personas puedan acceder a ellos mediante Internet.

Tipos de Hosting

Tipo Descripción
Compartido Varios sitios web utilizan los recursos de un mismo servidor.
VPS Proporciona un servidor virtual con recursos más controlados.
Nube Utiliza diferentes servidores conectados para proporcionar recursos y disponibilidad.

Vercel

Vercel es una plataforma utilizada para desplegar sitios web y proyectos frontend. Puede conectarse con un repositorio de GitHub y publicar automáticamente los archivos del proyecto.

¿Qué es un dominio?

Un dominio es el nombre que una persona escribe en el navegador para acceder a un sitio web. Por ejemplo: 

www.ejemplo.com

TLD

TLD significa Top-Level Domain. Es la extensión que aparece al final de un dominio.

TLD Ejemplo
.com www.ejemplo.com
.net www.ejemplo.net
.org www.ejemplo.org

Subdominio

Un subdominio es una dirección que pertenece a un dominio principal. 

blog.ejemplo.com

Propagación DNS

DNS significa Domain Name System. Su función principal es relacionar los nombres de dominio con las direcciones de los servidores.

USUARIO
→
DNS
→
DOMINIO
→

PÁGINA WEB

Cuando se modifica un registro DNS, la información debe actualizarse en diferentes servidores. Este proceso se conoce como propagación DNS y puede tardar un tiempo en reflejarse completamente.

Proceso para publicar un sitio

  1. Crear la página web.
  2. Guardar todos los archivos del proyecto.
  3. Crear un repositorio público en GitHub.
  4. Subir el proyecto al repositorio.
  5. Conectar GitHub con Vercel.
  6. Realizar el despliegue.
  7. Obtener el enlace público.
